# ATRIX Technologies

Sitio web de **ATRIX Technologies** — Nuevo Laredo, Tamaulipas.  
Dominio: [atrixnld.com](https://atrixnld.com)

## Desarrollo

```bash
cp .env.example .env.local
# Completa URL y anon key de Supabase
npm install
npm run dev
```

## Supabase

En el SQL Editor del proyecto, ejecuta [`supabase/schema.sql`](supabase/schema.sql) para crear la tabla `leads` del formulario de contacto.
